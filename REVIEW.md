# Самопроверка перед Pull Request
Проверены: деление на ноль, граница температур, верхний предел N,
независимость задач и продолжение меню после ошибочного ввода.
Ограничения: учебный консольный интерфейс, нет сохранения пользовательских вычислений.
Подготовка PR: загрузить ветки в свой GitHub/GitLab, выбрать main как базу,
сравнить изменения feature-ветки, выполнить review в интерфейсе сервиса.
Этот файл — локальный результат просмотра кода, а не подтверждение внешнего PR.
