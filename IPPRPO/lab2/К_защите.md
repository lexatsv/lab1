# К защите — Git
- Четыре задачи и отдельные ветки: primes, calculator, palindrome, temperature.
- Рабочее дерево — текущие файлы; индекс — подготовленные правки; коммит — снимок в истории.
- Merge объединяет ветки и может создать коммит с двумя родителями.
- Rebase переносит коммиты на другую базу; хеши меняются. Общую main не переписывали.
- Cherry-pick переносит выбранное изменение; здесь — проверку нижней границы температуры.
- Stash временно убирает незавершённые правки README; pop восстанавливает их.
- Revert добавляет отменяющий коммит, история сохраняется.
- Конфликты: Main.java между задачами, Calculator.title внутри задачи, messages.txt в ресурсе.
- .gitignore исключает out, class и файлы IDE.
- Локальный bare remote демонстрирует обмен. GitHub используется отдельно: PR №2 в lexatsv/lab1.
- В GitHub лабораторная находится в отдельной папке IPPRPO/lab2, прежние файлы сохранены.
- Проверка кода записана в REVIEW.md. Самостоятельно одобрять свой PR через Approve GitHub не позволяет.
- Показать git log --all --oneline --graph, git show и девять проверок SmokeTest.
